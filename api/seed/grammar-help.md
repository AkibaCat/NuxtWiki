## 标题

```md
# 一级标题（对应页面标题）
## 二级标题（出现在目录中）
### 三级标题（出现在目录中）
#### 四级标题
##### 五级标题
###### 六级标题
```

> 说明：二级（##）与三级（###）标题会自动生成目录导航（TOC），点击可跳转。

## [自定义着色与样式]{%section}

使用 `[文本]{颜色*}` 语法为文字着色。颜色*（大括号内）支持 **十六进制**、**RGB**、**类名** 与 **Scss 变量** 四种写法：

- 十六进制：`[示例]{3c9c5c}` → [示例]{3c9c5c}（也可写成 `[示例]{#3c9c5c}`）
- RGB：`[示例]{60:156:92}` → [示例]{60:156:92}
- 类名：`[示例]{%text}` → [示例]{%text} 套用页面样式表中定义的 `.text` 规则（`%` 后接类名，如 `%text` → `.text`）
- Scss 变量：`[示例]{$color}` → [示例]{$color} 套用页面样式表中定义的 `$color` 变量
- 主题色：`[示例]{$TC}` → [示例]{$TC} 内置主题色（`var(--ui-primary)`）
- 高亮内部仍可使用行内语法，例如 `[**加粗**]{$TC}` → [**加粗**]{$TC}

> 说明：十六进制可省略 `#` 前缀（`3c9c5c` 与 `#3c9c5c` 等价）；RGB 使用英文冒号分隔（红:绿:蓝），取值 0–255；`%` 后接类名（如 `%text` → `.text`），由本页样式表（“样式编辑器”）定义；`$` 后接 Scss 变量名，取页面样式表顶层变量；`$TC` 为内置特殊变量（站点主题色 `var(--ui-primary)`），不可被样式编辑器自定义。

## 容器

使用 `::: 类型 [文本]` 包裹一段内容，以独立成行的 `:::` 结束。可用类型：**info**、**tip**、**warning**、**danger**、**details**（折叠容器）。`[文本]`（标题）为可选项；各类型会使用对应的默认配色（背景与标题颜色）。

::: info
这是一条 **info** 提示。
:::

::: tip 小贴士
**tip** 容器，标题通过 `[文本]` 指定。
:::

::: warning
这是一个 **warning** 警告容器。
:::

::: danger
这是一个 **danger** 危险容器。
:::

::: details 点击展开查看详情
details 为折叠容器，点击标题即可展开/收起正文。
这里是折叠后的正文内容。
:::

> info / tip / warning / danger / details 的标题与背景分别呈现蓝、绿、橙、红、灰的默认配色。

## HTML 嵌套

本站支持 **HTML 白名单标签**，标签内部可以继续书写 Markdown（嵌套）。

### 行内标签

常用行内标签：`span`、`mark`、`strong`、`em`、`a`、`code`、`kbd`、`sub`、`sup`、`del`、`ins` 等。

示例：这是一段 <mark>高亮文字</mark>，文字中的 **加粗** 依然生效，2<sup>3</sup> = 8，H<sub>2</sub>O。

### 块级容器

常用块级容器：`div`、`section`、`details`、`summary`、`table`、`blockquote` 等。内部可以书写标题、列表、引用等块级语法。

<details>
<summary>折叠面板（点击展开）</summary>

点击前只显示上面的「summary」文字，展开后可以看到下面的内容：

- 列表项 A
- 列表项 B

</details>

> 提示：鼠标悬停在折叠面板的「summary」标题上会显示手型指针，表示可点击展开 / 收起。

### 原生 HTML 表格

单元格内同样支持 Markdown：

<table>
<tr>
<th>项目</th>
<th>说明</th>
</tr>
<tr>
<td>**加粗**</td>
<td>单元格内 Markdown 有效</td>
</tr>
<tr>
<td>`行内代码`</td>
<td>同样支持</td>
</tr>
</table>

### 原始内容与安全

`pre` 标签内部按原文展示，不解析 Markdown：

<pre>**加粗不会生效** <script>alert(1)</script></pre>

> 安全说明：非白名单标签会被转义，`javascript:` 等危险协议会被拦截，`on*` 事件属性会被过滤，请放心使用。
