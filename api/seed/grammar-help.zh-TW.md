## 標題

```md
# 一級標題（對應頁面標題）
## 二級標題（出現在目錄中）
### 三級標題（出現在目錄中）
#### 四級標題
##### 五級標題
###### 六級標題
```

> 說明：二級（##）與三級（###）標題會自動產生目錄導覽（TOC），點擊可跳轉。

## 文字樣式

- `**加粗**` → **加粗**
- `*斜體*` → *斜體*

- `` `行內程式碼` `` → `行內程式碼`

## [自訂著色與樣式]{%section}

使用 `[文字]{顏色*}` 語法為文字著色。顏色*（大括號內）支援 **十六進位**、**RGB**、**類名** 與 **Sass 變數** 四種寫法：

- 十六進位：`[範例]{3c9c5c}` → [範例]{3c9c5c}（也可寫成 `[範例]{#3c9c5c}`）
- RGB：`[範例]{60:156:92}` → [範例]{60:156:92}
- 類名：`[範例]{%text}` → [範例]{%text} 套用頁面樣式表中定義的 `.text` 規則（`%` 後接類名，如 `%text` → `.text`）
- Sass 變數：`[範例]{$color}` → [範例]{$color} 套用頁面樣式表中定義的 `$color` 變數
- 主題色：`[範例]{$TC}` → [範例]{$TC} 內建主題色（`var(--ui-primary)`）
- 高亮內部仍可使用行內語法，例如 `[**加粗**]{$TC}` → [**加粗**]{$TC}

> 說明：十六進位可省略 `#` 前置（`3c9c5c` 與 `#3c9c5c` 等價）；RGB 使用英文冒號分隔（紅:綠:藍），取值 0–255；`%` 後接類名（如 `%text` → `.text`），由本頁樣式表（「樣式編輯器」）定義；`$` 後接 Sass 變數名，取頁面樣式表頂層變數；`$TC` 為內建特殊變數（網站主題色 `var(--ui-primary)`），不可被樣式編輯器自訂。

## 容器

使用 `::: 類型 [文字]` 包裹一段內容，並以獨立成行的 `:::` 結束。可用類型：**info**、**tip**、**warning**、**danger**、**details**（折疊容器）。`[文字]`（標題）為可選項；各類型會使用對應的預設配色（背景與標題顏色）。

::: info
這是一條 **info** 提示。
:::

::: tip 小撇步
**tip** 容器，標題透過 `[文字]` 指定。
:::

::: warning
這是一個 **warning** 警告容器。
:::

::: danger
這是一個 **danger** 危險容器。
:::

::: details 點擊展開檢視詳情
details 為折疊容器，點擊標題即可展開/收起正文。
這裡是折疊後的正文內容。
:::

> info / tip / warning / danger / details 的標題與背景分別呈現藍、綠、橙、紅、灰的預設配色。

## HTML 巢狀

本站支援 **HTML 白名單標籤**，標籤內部可以繼續撰寫 Markdown（巢狀）。

### 行內標籤

常用行內標籤：`span`、`mark`、`strong`、`em`、`a`、`code`、`kbd`、`sub`、`sup`、`del`、`ins` 等。

範例：這是一段 <mark>高亮文字</mark>，文字中的 **加粗** 依然生效，2<sup>3</sup> = 8，H<sub>2</sub>O。

### 區塊容器

常用區塊容器：`div`、`section`、`details`、`summary`、`table`、`blockquote` 等。內部可以書寫標題、清單、引用等區塊語法。

<details>
<summary>摺疊面板（點擊展開）</summary>

點擊前只顯示上面的「summary」文字，展開後可以看到下面的內容：

- 清單項 A
- 清單項 B

</details>

> 提示：滑鼠懸停在摺疊面板的「summary」標題上會顯示手型指標，表示可點擊展開 / 收起。

### 原生 HTML 表格

儲存格內同樣支援 Markdown：

<table>
<tr>
<th>項目</th>
<th>說明</th>
</tr>
<tr>
<td>**加粗**</td>
<td>儲存格內 Markdown 有效</td>
</tr>
<tr>
<td>`行內程式碼`</td>
<td>同樣支援</td>
</tr>
</table>

### 原始內容與安全

`pre` 標籤內部按原文展示，不解析 Markdown：

<pre>**加粗不會生效** <script>alert(1)</script></pre>

> 安全說明：非白名單標籤會被跳脫（轉義），`javascript:` 等危險協定會被攔截，`on*` 事件屬性會被過濾，請安心使用。
